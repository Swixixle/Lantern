Why this can fail even with step flow
	•	A refresh or state desync can land the UI on “export” step with missing extractedData (especially if step is derived from local pack existence rather than extract success).
	•	Even if buttons are only shown post-success, double-clicks and edge timing (status flips, state not yet populated) can still throw.

Minimal patch to close Invariant 4 decisively

	2.	Disable buttons and guard handlers:

<Button onClick={() => canExport && downloadJSON()} disabled={!canExport} ...>

  console.warn("[Export] Blocked: extract not ready");
  return;
}

This turns “reachable only after completion” into a real invariant.
