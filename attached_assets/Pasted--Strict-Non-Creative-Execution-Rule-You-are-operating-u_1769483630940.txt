# v1.22 — Verifier Enhancement (snapshot_proof_index.json validation)

## 0) Goal (scope-locked)

Extend the bundle verifier to validate `snapshot_proof_index.json` if present.

No new exports. Only verification.

---

## 1) Output schema additions (extend, do not remove)

Add:

```json
{
  "snapshot_index_ok": true,
  "snapshot_index_checked": 0,
  "snapshot_index_issues": []
}
```

If `snapshot_proof_index.json` missing:

* `snapshot_index_ok: null`
* `snapshot_index_checked: 0`
* `snapshot_index_issues: ["snapshot_proof_index.json not present; skipping"]`

If present and any check fails:

* `snapshot_index_ok: false`
* `bundle_ok` must be false
* `snapshot_index_issues` contains issue codes from §2 (strings)

---

## 2) Verification rules (exact)

If `snapshot_proof_index.json` exists:

### A) Required top-level keys (exact set)

Must contain exactly:

* `corpus_id`
* `snapshots`

Issue:

* `SNAPSHOT_INDEX_KEYS_INVALID`

### B) snapshots is array

Issue:

* `SNAPSHOT_INDEX_NOT_ARRAY`

### C) Sorting

Verify `snapshots[]` sorted lexicographically by `snapshot_id`.

Issue:

* `SNAPSHOT_INDEX_NOT_SORTED`

### D) Entry schema + hash validation

For each entry, keys must be exactly:

* `snapshot_id`
* `created_at`
* `hash_alg`
* `hash_hex`

Validate:

* `hash_alg` must equal `"SHA-256"`
* `hash_hex` must be 64-hex lowercase

Issues:

* `SNAPSHOT_INDEX_ENTRY_KEYS_INVALID`
* `SNAPSHOT_INDEX_HASH_INVALID`

### E) Cross-file existence

For each entry:

* Verify corresponding snapshot file exists:
  `snapshots/<snapshot_id>.json`

Issue:

* `SNAPSHOT_INDEX_FILE_MISSING`

Set `snapshot_index_checked` = number of snapshot entries processed.

---

## 3) Acceptance tests

1. Valid bundle with empty snapshots[] → `snapshot_index_ok:true`, checked=0.
2. Add one snapshot entry but remove the corresponding snapshot file → `SNAPSHOT_INDEX_FILE_MISSING` and bundle_ok false.
3. Shuffle entries order → `SNAPSHOT_INDEX_NOT_SORTED`.
4. Tamper hash_alg or hash length → `SNAPSHOT_INDEX_HASH_INVALID`.

---

## 4) What to send me when complete

Return ONLY:

1. Verifier output JSON for valid bundle (snapshot_index_ok=true)
2. Verifier output JSON for failing case (SNAPSHOT_INDEX_FILE_MISSING or HASH_INVALID)

Proceed exactly to v1.22.
