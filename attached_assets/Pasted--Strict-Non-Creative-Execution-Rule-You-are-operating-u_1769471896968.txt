# v1.5 — Corpus State Seal (Chain-of-Custody, Deterministic)

## 0) Goal (scope-locked)

Add:

1. The ability to **seal** a corpus state as a snapshot with a stable ID (already exists), and
2. The ability to generate an evidence packet **that references the snapshot it was derived from**, and
3. A verifiable linkage record.

No changes to hashing logic already implemented. Only add linkage fields and verification.

---

## 1) Data model changes

## A) Snapshot: add `snapshot_scope`

Add:

```ts
snapshot_scope: {
  includes_claim_ids: string[];     // sorted
  includes_source_ids: string[];    // sorted
}
```

Populate at snapshot creation:

* includes_claim_ids = all claim IDs returned by `GET /api/corpus/:id/claims` at save-time
* includes_source_ids = all source IDs returned by `GET /api/corpus/:id/sources` at save-time

No inference. Just IDs.

## B) EvidencePacket: add snapshot linkage (required)

Add to packet payload:

```ts
snapshot_id: string;    // required
snapshot_hash_hex: string; // required (copied from snapshot)
```

Hard rule:

* Packets must be generated **against a specific snapshot**.

---

## 2) API changes (minimal)

### A) Create packet now requires snapshot_id

Update endpoint:
`POST /api/corpus/:corpus_id/claims/:claim_id/packet`

Request:

```json
{ "snapshot_id": "uuid" }
```

Server validation:

* snapshot.corpus_id must match
* claim.corpus_id must match
* claim.id must be included in snapshot_scope.includes_claim_ids
* all claim.anchor_ids must exist in the corpus at time of packet generation (existence check only)

Response: EvidencePacket including snapshot_id and snapshot_hash_hex.

### B) New endpoint: verify packet against snapshot

`GET /api/packets/:packet_id/verify_chain`

Response:

```json
{
  "packet_id": "uuid",
  "verified_packet_hash": true,
  "verified_snapshot_hash": true,
  "snapshot_id": "uuid",
  "snapshot_hash_match": true,
  "claim_in_snapshot_scope": true,
  "sources_in_snapshot_scope": true
}
```

Definitions:

* verified_packet_hash: existing packet verify logic
* verified_snapshot_hash: call snapshot verify logic
* snapshot_hash_match: packet.snapshot_hash_hex equals snapshot.hash_hex
* claim_in_snapshot_scope: packet.claim.id is in snapshot_scope.includes_claim_ids
* sources_in_snapshot_scope: for each anchor.source_id in packet, that source_id is in snapshot_scope.includes_source_ids

No other checks.
