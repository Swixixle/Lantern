# v1.15 — Bundle Verifier Enhancement (Verify anchors_proof_index against pages + anchor proofs)

## 0) Goal (scope-locked)

Extend the **v1.8 verifier** so that when a bundle contains:

* `anchors_proof_index.json`
* `pages/<source_id>/page-<page_index>.json`

…the verifier performs additional deterministic checks and reports pass/fail in JSON.

No network access. No PDF parsing. Only bundle contents.

---

## 1) Verifier input/output change

### Input

Same CLI:

```bash
node tools/verify_bundle.js <bundle.zip> --strict=true
```

### Output schema (extend, do not remove existing keys)

Add:

```json
{
  "anchors_index_ok": true,
  "anchors_index_checked": 2,
  "anchors_index_mismatches": [
    {
      "anchor_id": "uuid",
      "issue": "PAGE_TEXT_HASH_MISMATCH",
      "expected": "64-hex",
      "actual": "64-hex",
      "path": "pages/<source_id>/page-<n>.json"
    }
  ]
}
```

Rules:

* If `anchors_proof_index.json` missing, set:

  * `anchors_index_ok: null`
  * `anchors_index_checked: 0`
  * `anchors_index_mismatches: []`
  * add note: `"anchors_proof_index.json not present; skipping"`
* `bundle_ok` must incorporate anchors_index_ok when it is not null:

  * If `anchors_index_ok === false`, `bundle_ok` must be false.

---

## 2) Verification rules (exact)

If `anchors_proof_index.json` exists:

1. Parse it and verify top-level keys exist: `corpus_id`, `extractor`, `anchors`.
2. Verify extractor exact:

   * name == `"pdfjs-text-v1"`
   * version == `"1.0.0"`
3. Verify `anchors` is an array.
4. Verify `anchors` is sorted lexicographically by `anchor_id`.
5. For each anchor entry:

   * Verify required keys exist: `anchor_id, source_id, page_index, quote_start_char, quote_end_char, page_text_sha256_hex`
   * Verify `page_index` is integer >= 0
   * Locate corresponding page json:

     * `pages/<source_id>/page-<page_index>.json`
   * Parse it and read `page_text_sha256_hex`
   * Assert equality with anchor entry `page_text_sha256_hex`
6. Count checked anchors.

Mismatch reporting:

* If page json missing → issue `PAGE_JSON_MISSING`, expected = anchor.page_text_sha256_hex, actual = null
* If hash mismatch → `PAGE_TEXT_HASH_MISMATCH`
* If sort order wrong → one mismatch with issue `ANCHORS_NOT_SORTED` (anchor_id can be null)

---

## 3) Acceptance tests

1. Valid bundle with anchors_proof_index passes with:

   * `anchors_index_ok: true`
   * `anchors_index_checked > 0`
2. Remove one page json file → `anchors_index_ok: false` with PAGE_JSON_MISSING mismatch
3. Tamper page json hash value → `anchors_index_ok: false` with PAGE_TEXT_HASH_MISMATCH
4. Shuffle anchors order → `anchors_index_ok: false` with ANCHORS_NOT_SORTED
