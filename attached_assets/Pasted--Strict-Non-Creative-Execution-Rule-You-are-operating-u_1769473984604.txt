# v1.10 — Repro Pack (Single ZIP: Bundle + Verifier + Instructions)

## 0) Goal (scope-locked)

Generate one ZIP that contains:

* The **corpus bundle ZIP** (from v1.7)
* The **CLI verifier script** (from v1.8)
* A pinned **package-lock** / minimal node deps metadata to run the verifier
* A deterministic `INSTRUCTIONS.txt`
* A top-level `REPRO_MANIFEST.json` that hashes every included file

No analysis. No interpretation.

---

## 1) New endpoint (protected by auth)

`GET /api/corpus/:corpus_id/export_repro_pack`
Optional query params:

* `include_raw_sources=true|false` (default false)
* `strict=true|false` (default true) — intended verifier mode

Response:

* `Content-Type: application/zip`
* Filename: `lantern-repro-pack-<corpus_id>.zip`

---

## 2) ZIP contents (exact structure)

```
lantern-repro-pack-<corpus_id>/
  REPRO_MANIFEST.json
  INSTRUCTIONS.txt
  bundle/
    lantern-corpus-<corpus_id>.zip
  verifier/
    verify_bundle.js          (or .ts compiled to .js; must be runnable by node)
    package.json
    package-lock.json
```

Hard rule:

* Do not include source code outside verifier.
* Do not include node_modules.

---

## 3) INSTRUCTIONS.txt (exact content)

Use exactly this text (no edits):

```
LANTERN REPRO PACK (v1)

Contents:
- bundle/lantern-corpus-<corpus_id>.zip
- verifier/verify_bundle.js
- verifier/package.json
- verifier/package-lock.json

How to verify (requires Node.js 18+):
1) cd verifier
2) npm ci
3) node verify_bundle.js ../bundle/lantern-corpus-<corpus_id>.zip --strict=<strict>

Expected result:
- "bundle_ok": true

Notes:
- This verifier checks MANIFEST.json integrity and file SHA-256 hashes.
- No network access is required.
```

Replace `<corpus_id>` and `<strict>` placeholders with real values when writing the file.

---

## 4) REPRO_MANIFEST.json (deterministic)

### Shape

```json
{
  "repro_format": "lantern-repro-pack-v1",
  "corpus_id": "uuid",
  "include_raw_sources": false,
  "strict": true,
  "files": [
    { "path": "INSTRUCTIONS.txt", "sha256_hex": "..." },
    { "path": "bundle/lantern-corpus-<corpus_id>.zip", "sha256_hex": "..." },
    { "path": "verifier/verify_bundle.js", "sha256_hex": "..." },
    { "path": "verifier/package.json", "sha256_hex": "..." },
    { "path": "verifier/package-lock.json", "sha256_hex": "..." }
  ],
  "hash_alg": "SHA-256",
  "hash_hex": "..."
}
```

### Hash rules

* `files[]` sorted lexicographically by `path`
* `sha256_hex` computed on exact bytes in ZIP
* `hash_hex` is sha256 of canonical JSON excluding:

  * `hash_hex`
* Canonical key order:
  `repro_format, corpus_id, include_raw_sources, strict, files, hash_alg`

No `generated_at` field (do not add).
