# v1.12 — Public Review Link (Read-only Deep Link)

## 0) Goal (scope-locked)

When `LANTERN_PUBLIC_READONLY=true`, enable a reviewer to open a single URL and land directly on a corpus’s Claim Space, with navigation to:

* Sources
* Anchors browser
* Ledger
* Snapshots list
* Packets view (by packet id if shared)

No writes. No auth.

---

## 1) New route (client)

Add:
`/review/:corpus_id`

Behavior:

* On load, navigate internally to Claim Space with that corpus id:

  * `/?corpusId=<corpus_id>`
* Must preserve review context (i.e., do not require API key input).

No additional UI beyond redirect/routing.

---

## 2) Read-only navigation bar (client)

When `isReadOnly=true`, show a simple nav (top or side) with exact links:

* Claim Space → `/?corpusId=<id>`
* Sources → `/sources?corpusId=<id>`
* Anchors → `/anchors/browse?corpusId=<id>`
* Ledger → `/ledger?corpusId=<id>`
* Snapshots → `/snapshots?corpusId=<id>`

No other items.

If `isReadOnly=false`, do not show this nav (unchanged behavior).

---

## 3) New Sources page (client) — read-only

Route:
`/sources?corpusId=<id>`

Calls:
`GET /api/corpus/:corpus_id/sources`

Displays table:

* role
* filename
* sha256_hex
* uploaded_at
* source_id

No upload controls on this page (ever).

---

## 4) Acceptance tests

1. With `public_readonly=true`, open `/review/<corpus_id>` with no auth → lands on Claim Space for that corpus.
2. Read-only nav is visible and links resolve.
3. Sources page loads and displays sources via unauthenticated GET.
4. No write controls appear anywhere in review mode.
