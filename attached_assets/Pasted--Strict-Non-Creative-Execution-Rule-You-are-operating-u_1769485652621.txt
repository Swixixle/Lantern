# v1.25 — Ledger Proof Index in Exports (Deterministic)

## 0) Goal (scope-locked)

Add a deterministic index file to the **v1.7 corpus bundle export** that allows auditors to enumerate revision ledger events and verify event hashes exist, without calling APIs.

No inference. Only stored fields.

---

## 1) Bundle structure change

Add file at bundle root:
`ledger_proof_index.json`

Include it in `MANIFEST.json` `files[]` with sha256 like all other files.

---

## 2) File format (exact)

`ledger_proof_index.json`:

```json
{
  "corpus_id": "uuid",
  "events": [
    {
      "event_id": "uuid",
      "occurred_at": "ISO-8601",
      "event_type": "string",
      "entity_type": "string",
      "entity_id": "string",
      "hash_alg": "SHA-256",
      "hash_hex": "64-hex"
    }
  ]
}
```

Hard rules:

* `events[]` includes **every ledger event** for the corpus.
* Values must come from stored ledger event records:

  * `event_type` from the stored event_type string (exact, no normalization)
  * entity fields from stored entity object: `entity.entity_type`, `entity.entity_id`
  * `hash_alg` must be exactly `"SHA-256"` for every entry
  * `hash_hex` from stored event hash
* No extra keys anywhere.
* `events[]` must be sorted lexicographically by `event_id` (string compare).
* Top-level key order must be exactly:

  1. `corpus_id`
  2. `events`

---

## 3) Determinism requirements

* Stable JSON serialization (choose minified or 2-space indent; be consistent every time).
* Two exports of unchanged corpus produce identical sha256 for `ledger_proof_index.json`.

---

## 4) Acceptance tests

1. Export bundle includes `ledger_proof_index.json` at root.
2. `ledger_proof_index.json` contains correct `corpus_id` and one entry per ledger event in corpus.
3. `events[]` sorted by `event_id`.
4. MANIFEST includes `ledger_proof_index.json` with correct sha256.
5. Determinism: sha256 identical across two exports without corpus changes.
6. Hash validation: every `hash_hex` is 64-hex lowercase; every `hash_alg` equals `"SHA-256"`.

---

## 5) What to send me when complete

Return ONLY:

1. Full `ledger_proof_index.json`
2. MANIFEST entry for it (path + sha256_hex)
3. Determinism check (two sha256 sums)
4. One sample event entry copied from the index plus the matching event object in `ledger.json` showing same `event_id` and `hash_hex`

Proceed exactly to v1.25.
