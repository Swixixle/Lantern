# v1.28 — Review Mode: Deterministic “Audit Line” Export (Corpus-Level)

## 0) Goal (scope-locked)

Add a deterministic corpus-level plaintext export that lists one line per **anchor** in the corpus in a stable format for external audit.

No inference. Only stored fields already present in anchor proof / provenance.

---

## 1) Server endpoint (public-readonly aware)

Add:

`GET /api/review/:corpusId/audit_lines`

Rules:

* If `public_readonly=false`: return 401 AUTH_ERROR with `{"type":"AUTH_ERROR","message":"Unauthorized"}`
* If `public_readonly=true`: return 200 `text/plain; charset=utf-8`

Body: newline-separated lines, each line formatted exactly:

```
<anchor_id>|<source_id>|<page_index>|<quote_start_char>|<quote_end_char>|<page_text_sha256_hex>|<substring_sha256_hex>
```

Where:

* All fields come from stored data:

  * `anchor_id` from anchor.id
  * `source_id`, `page_index`, `quote_start_char`, `quote_end_char` from anchor.provenance
  * `page_text_sha256_hex` from `pdf_pages` for (source_id,page_index)
  * `substring_sha256_hex` must equal sha256 of the exact substring defined by [quote_start_char, quote_end_char] from the stored page text (same substring used by anchor proof repro)
* Include **only anchors that have provenance.extractor.name === "pdfjs-text-v1"**
* Sort lines lexicographically by `anchor_id` (string compare)
* Final output must end with a single trailing newline `\n`

---

## 2) Client route (read-only)

Add:

`/review/:corpusId/audit_lines`

Page shows:

* Title: `Audit Lines`
* Corpus ID displayed
* One button: `Download audit_lines.txt`

  * links to `/api/review/:corpusId/audit_lines`
* No other UI

---

## 3) Acceptance tests

1. public_readonly=true: GET returns text/plain with N lines for eligible anchors, sorted by anchor_id, trailing newline present.
2. public_readonly=false: GET returns 401 Unauthorized payload exactly.
3. For one anchor, computed substring sha256 matches the last field in its line.
4. `/review/:corpusId/audit_lines` route loads and download link points to correct endpoint.
