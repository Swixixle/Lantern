1. What’s Actually Happening (Zoomed Out)

If the app:
	•	Builds successfully
	•	Server says “running”
	•	Preview loads a white screen forever
	•	No visible error overlay

Then one of these is true 90% of the time:

A. The client bundle is failing before React mounts

Examples:
	•	index.tsx never runs
	•	createRoot(...).render(<App />) never executes
	•	An import throws silently before render

B. The app is mounted to a DOM node that doesn’t exist

Example:

createRoot(document.getElementById("root")!)

…but index.html no longer has <div id="root"></div>

C. Routing mismatch (VERY likely in your case)

You recently:
	•	Changed landing routes
	•	Swapped dashboards
	•	Added /library, /extract, /compare

If React Router is rendering nothing at /, you get a white screen with no error.

D. Vite preview + Replit proxy mismatch

Replit sometimes serves / but your app expects /index.html or a base path.

⸻

2. What YOU Can Check in 2 Minutes (No Agent)

Step 1: Open the Browser Console (critical)

In the Preview pane:
	•	Click Console tab (not Replit console)
	•	Or right-click → Inspect → Console

You are looking for:
	•	Red errors
	•	Even one warning

If you see nothing at all, that tells us React never mounted.

⸻

Step 2: Check the DOM

In the Elements tab, look for:

<div id="root"></div>

If it’s missing → that’s the bug.

⸻

Step 3: Hard-refresh the preview

Replit caches aggressively.

Do this exactly:
	•	Stop the server
	•	Run again
	•	In preview, click the ⟳ icon
	•	If still white → click Open in Browser (important)

If it works in “Open in browser” but not Preview → it’s a Replit proxy issue, not your code.

⸻

3. The MOST LIKELY Lantern-Specific Cause

Based on everything you’ve done:

You changed the landing page to “Library”, but / no longer renders anything.

This usually looks like:

<Routes>
  <Route path="/library" element={<Library />} />
  <Route path="/extract" element={<Extract />} />
  <Route path="/compare" element={<Compare />} />
</Routes>

But no route for /.

React Router does NOT error on this.
It just renders nothing.
Hence: white screen.

⸻

4. The Fix (Minimal, Safe, Non-Destructive)

Option A (Recommended): Redirect / → /library

import { Navigate } from "react-router-dom";

<Routes>
  <Route path="/" element={<Navigate to="/library" replace />} />
  <Route path="/library" element={<Library />} />
  <Route path="/extract" element={<Extract />} />
  <Route path="/compare" element={<Compare />} />
</Routes>

This preserves everything you built.

⸻

Option B: Make Library the root route

<Route path="/" element={<Library />} />

Simpler, but less explicit.
