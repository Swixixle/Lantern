4) The top 5 actual causes (fix in this order)

Cause 1: Wrong port / host binding

Ensure dev server binds correctly:
	•	If Vite is used, set:

// vite.config.ts
export default defineConfig({
  server: { host: true, port: 5000, strictPort: true },
});

And ensure Replit starts the correct command.

Cause 2: Serving dist but running dev code (or vice versa)

Pick ONE mode:

Dev mode
	•	Start Vite dev server and do NOT serve dist.

Prod mode
	•	Build to dist and serve dist from Express.
	•	Ensure Express has:
	•	app.use(express.static(distPath))
	•	app.get("*", send index.html) for SPA routing

Cause 3: MIME type / module loading error

If Network shows JS requests returning HTML, you’ll get:
	•	“Failed to load module script… MIME type text/html”
Fix your static routing. Your assets path is wrong.

Cause 4: React Router basename / bad route redirect loop

If you have Router misconfigured you can get blank.
	•	Temporarily render a plain <div>Router bypass OK</div> to confirm.

Cause 5: Runtime exception

If Console shows an exception, fix that exact line first. Do not refactor.
