What the error means (plain English)

This line is the smoking gun:

Error: listen EADDRINUSE: address already in use 0.0.0.0:5000

Translation:

👉 Your app is trying to start two servers on the same port (5000)
👉 Replit allows only one process per port
👉 When the second one starts, Node crashes
👉 When Node crashes, Preview stays white forever

So the UI cannot load because the server never successfully stays up.

This has nothing to do with Preview buttons, URLs, or /__boot.
The backend is killing itself before the browser ever gets a chance.

⸻

Why this happened (likely causes)

One (or more) of these is true in your project:
	1.	You are calling app.listen(5000) more than once
	2.	You have two server entry points both starting servers
	3.	A dev watcher restarted without killing the previous process
	4.	Vite + Express are both trying to bind the same port

Your screenshots show Express is already serving, then something else tries to listen again.

The fix (do this exactly)

Step 1 — STOP EVERYTHING

In Replit:
	•	Click Stop (red square)
	•	Wait 10 seconds
	•	Confirm Console is quiet

This clears the stuck port.

⸻

Step 2 — Open server/index.ts

Look for any line like this:

app.listen(5000, () => {
  console.log("Server running");
});

or

server.listen(5000);

You must ensure this exists only ONCE in the entire repo.

⸻

Step 3 — Make port usage explicit and safe

Change your listen code to this (exactly):

const PORT = process.env.PORT || 3000;

app.listen(PORT, () => {
  console.log(`Server listening on ${PORT}`);
});

Why:
	•	Replit injects process.env.PORT
	•	Hardcoding 5000 causes conflicts
	•	This prevents double-binding crashes

⸻

Only one file should start the server.
