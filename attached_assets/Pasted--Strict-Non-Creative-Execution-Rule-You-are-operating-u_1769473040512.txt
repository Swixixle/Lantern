# v1.7 — Export Bundle (ZIP, Deterministic)

## 0) Goal (scope-locked)

Generate a deterministic ZIP bundle for a corpus containing:

* Corpus metadata
* Source manifest (filenames + sha256)
* Snapshots (JSON)
* Evidence packets (JSON)
* Ledger (JSON)
* A top-level `MANIFEST.json` with hashes of every included file

No summaries. No analysis. No rewriting.

Raw uploaded PDFs are **excluded by default**.

---

## 1) New endpoint

### `GET /api/corpus/:corpus_id/export_bundle`

Optional query params:

* `include_raw_sources=true|false` (default false)

Response:

* `Content-Type: application/zip`
* Attachment filename: `lantern-corpus-<corpus_id>.zip`

---

## 2) ZIP contents (exact structure)

```
lantern-corpus-<corpus_id>/
  MANIFEST.json
  corpus.json
  sources.json
  ledger.json
  snapshots/
    <snapshot_id>.json
  packets/
    <packet_id>.json
  raw_sources/                     (only if include_raw_sources=true)
    <source_id>__<filename>
```

Hard rules:

* Directory and file names must match exactly.
* JSON files are UTF-8.

---

## 3) File payload rules (exact)

### A) `corpus.json`

Exact response shape of `POST /api/corpus` output:

```json
{ "corpus_id": "...", "created_at": "...", "purpose": "..." }
```

### B) `sources.json`

Exact response shape of `GET /api/corpus/:id/sources`:

```json
{ "corpus_id": "...", "sources": [ ... ] }
```

### C) `ledger.json`

Exact response shape of `GET /api/corpus/:id/ledger` (use limit=500):

```json
{ "corpus_id": "...", "events": [ ... ] }
```

### D) `snapshots/<snapshot_id>.json`

Exact response shape of `GET /api/snapshots/:id`

### E) `packets/<packet_id>.json`

Exact response shape of `GET /api/packets/:packet_id`

### F) `raw_sources/*` (optional)

Store exact uploaded bytes as originally received.

Filename rule:
`<source_id>__<filename>` (double underscore)

---

## 4) MANIFEST.json (deterministic)

### Shape

```json
{
  "bundle_format": "lantern-corpus-bundle-v1",
  "corpus_id": "uuid",
  "generated_at": "ISO",
  "include_raw_sources": false,
  "files": [
    {
      "path": "corpus.json",
      "sha256_hex": "..."
    },
    ...
  ],
  "manifest_hash_alg": "SHA-256",
  "manifest_hash_hex": "..."
}
```

### Hashing rules

* For each file in `files[]`, compute sha256 of the exact bytes included in the ZIP.
* `files[]` must be sorted lexicographically by `path`.
* `manifest_hash_hex` is sha256 of canonical JSON of the manifest excluding:

  * `manifest_hash_hex`
  * `generated_at` (exclude to keep determinism across time)

Canonicalization:

* stable JSON stringify
* keys ordered as: bundle_format, corpus_id, include_raw_sources, files, manifest_hash_alg

---

## 5) Determinism constraints

To prevent bundle drift:

* Snapshots included must be all snapshots for the corpus (no filtering).
* Packets included must be all packets for the corpus (no filtering).
* Ledger uses limit=500; if >500 exists, return 400 with message:
  `"Ledger exceeds export limit; increase limit support before exporting."`
* Within ZIP, file ordering must be deterministic (most zip libraries allow stable addition order; add files in sorted path order).
