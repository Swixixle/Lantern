# Next Specification — Corpus Intake + Source Registry (v1.1)

## 0) Goal (scope-locked)

Enable the system to:

* Register a corpus
* Register documents as **Primary** or **Secondary**
* Persist that registry
* Use `corpus_id` consistently across:

  * Claims
  * Anchors
  * Constraints
  * Snapshots

This does **not** introduce extraction, summarization, or automatic claim generation.

---

## 1) Data Model

Create `client/src/lib/schema/corpus.ts` (and server equivalents):

```ts
export type SourceRole = "PRIMARY" | "SECONDARY";

export interface Corpus {
  corpus_id: string;        // stable UUID
  created_at: string;       // ISO
  purpose: "Litigation support" | "Investigative journalism" | "Compliance/Internal Review" | "Research/Exploratory";
}

export interface CorpusSource {
  source_id: string;        // UUID
  corpus_id: string;
  role: SourceRole;
  filename: string;
  uploaded_at: string;      // ISO
  sha256_hex: string;       // hash of raw file bytes
}
```

Hard rule:

* `sha256_hex` must be computed from the uploaded file bytes. No approximations.

---

## 2) API Endpoints (minimum set)

### A) Create corpus

`POST /api/corpus`

Request:

```json
{ "purpose": "Litigation support" }
```

Response:

```json
{ "corpus_id": "uuid", "created_at": "ISO", "purpose": "Litigation support" }
```

### B) Upload source into corpus

`POST /api/corpus/:corpus_id/sources` (multipart/form-data)
Fields:

* `role`: PRIMARY | SECONDARY
* `file`: binary

Response:

```json
{
  "source_id": "uuid",
  "corpus_id": "uuid",
  "role": "PRIMARY",
  "filename": "Master Services Agreement v2.1.pdf",
  "uploaded_at": "ISO",
  "sha256_hex": "..."
}
```

### C) List corpus sources

`GET /api/corpus/:corpus_id/sources`

Response:

```json
{ "corpus_id": "uuid", "sources": [ /* CorpusSource[] */ ] }
```

No other endpoints.
