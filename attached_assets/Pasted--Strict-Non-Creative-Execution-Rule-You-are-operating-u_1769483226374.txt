# v1.21 — Snapshot Proof Index (Deterministic)

## 0) Goal (scope-locked)

Add a deterministic index file to the v1.7 export bundle that allows auditors to verify which snapshots exist and what their hashes are, without calling APIs.

No inference. Only stored snapshot fields.

---

## 1) Bundle structure change

Add file at bundle root:
`snapshot_proof_index.json`

Include in MANIFEST `files[]` with sha256.

---

## 2) File format (exact)

```json
{
  "corpus_id": "uuid",
  "snapshots": [
    {
      "snapshot_id": "uuid",
      "created_at": "ISO-8601",
      "hash_alg": "SHA-256",
      "hash_hex": "64-hex"
    }
  ]
}
```

Hard rules:

* snapshots[] includes every snapshot in the corpus.
* Values must come from stored snapshot record fields (not recomputed).
* snapshots[] sorted lexicographically by snapshot_id.
* Top-level key order exactly:

  1. corpus_id
  2. snapshots

---

## 3) Determinism

* Stable JSON serialization and ordering.
* Two exports unchanged corpus produce identical sha256 for snapshot_proof_index.json.

---

## 4) Acceptance tests

1. snapshot_proof_index.json included at bundle root and in MANIFEST.
2. snapshots[] count matches number of snapshot files in `snapshots/` directory.
3. For each entry, verify corresponding file exists: `snapshots/<snapshot_id>.json`.
4. Sorted order correct.
5. Determinism check passes (sha256 identical across two exports).

---

## 5) What to send me when complete

Return ONLY:

1. Full snapshot_proof_index.json
2. MANIFEST entry for it (path + sha256_hex)
3. Determinism check (two sha256 sums)
4. One cross-check showing one snapshot_id exists as `snapshots/<id>.json`

Proceed exactly to v1.21.
