# v1.17 — Verifier Enhancement (audit_summary.json validation)

## 0) Goal (scope-locked)

Extend the v1.8/v1.15 bundle verifier to validate `audit_summary.json` if present.

No new bundle content. Only verification.

---

## 1) Output schema additions (extend, do not remove)

Add:

```json
{
  "audit_summary_ok": true,
  "audit_summary_issues": []
}
```

If `audit_summary.json` missing:

* `audit_summary_ok: null`
* `audit_summary_issues: ["audit_summary.json not present; skipping"]`

If present and any check fails:

* `audit_summary_ok: false`
* `bundle_ok` must be false
* `audit_summary_issues` lists exact issue codes (strings) from §2.

---

## 2) Verification rules (exact)

If `audit_summary.json` exists:

### A) Required top-level keys present (exact set)

Must contain exactly these keys (no extras):

* `corpus_id`
* `sources`
* `pages`
* `anchors`
* `claims`
* `snapshots`
* `packets`
* `ledger_events`
* `extractor`

Issue code if fail:

* `AUDIT_SUMMARY_KEYS_INVALID`

### B) Extractor rule

* If any `pages/<source_id>/page-<n>.json` exists in bundle:

  * extractor.name must equal `"pdfjs-text-v1"`
  * extractor.version must equal `"1.0.0"`
    Else:
  * extractor.name must be null
  * extractor.version must be null

Issue code:

* `AUDIT_SUMMARY_EXTRACTOR_INVALID`

### C) Counts are non-negative integers

Validate these are integers >= 0:

* sources.count
* pages.count
* anchors.count
* claims.count
* snapshots.count
* packets.count
* ledger_events.count
  All values inside:
* sources.by_role[*]
* anchors.by_source_id[*]
* claims.by_classification[*]
* ledger_events.by_type[*]

Issue code:

* `AUDIT_SUMMARY_COUNTS_INVALID`

### D) Required subkeys exist

* sources.by_role exists (object)
* anchors.by_source_id exists (object)
* claims.by_classification exists (object)
* ledger_events.by_type exists (object)

Issue code:

* `AUDIT_SUMMARY_STRUCTURE_INVALID`

### E) Cross-check minimal internal consistency (no inference)

* sources.count must equal sum of sources.by_role values
* anchors.count must equal sum of anchors.by_source_id values
* claims.count must equal sum of claims.by_classification values

Issue code:

* `AUDIT_SUMMARY_SUM_MISMATCH`

Do **not** validate ledger_events.count against by_type sum (event types may be partial). Only validate that by_type values are valid integers.
