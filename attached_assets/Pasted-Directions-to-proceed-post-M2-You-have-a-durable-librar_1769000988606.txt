Directions to proceed (post-M2)

You have a durable library substrate. Proceed in the following order; do not skip steps.

M3 — Public Figure Pack v1 (Schema + UI capture)

1) Lock the Pack v1 schema (single source of truth)

Create client/src/lib/schema/pack_v1.ts (or equivalent) and define these primitives:
	•	Entity
	•	id, type (person|org|role|asset|publication|event), name, aliases[], tags[]
	•	Edge (relationship)
	•	id, fromEntityId, toEntityId, type (controlled enum), startDate?, endDate?, notes?
	•	Evidence
	•	id, sourceType, publisher?, title, url?, date, excerpt?, localHash?, notes?
	•	Claim
	•	id, text, claimType (fact|allegation|inference|opinion), confidence (0–1 or discrete),
evidenceIds[], counterEvidenceIds[], createdAt

Pack root:
	•	packId, packType: "public_figure" | "topic_ecosystem", schemaVersion: 1, subjectName, timestamps

Definition of done: a pack can represent a figure, their network, and claims with attached evidence.

3) Build a minimal “Capture” UI (do not boil ocean)
