## Step 5 — 90% likely causes (based on your repo + recent work)

Given your M2 work and file list, the most likely culprits are:

### 1) Import/export mismatch

Very common after refactors.

Example:

```ts
import { extract } from "@/lib/lanternExtract";
```

but file actually exports:

```ts
export default extract;
```

or vice versa.

### 2) TypeScript syntax error Vite doesn’t like

Examples:

* stray trailing comma
* unterminated generic
* malformed enum
* `as const` misuse

### 3) File moved / renamed but import path not updated

Especially casing issues:

```ts
./LanternExtract.ts
```

vs

```ts
./lanternExtract.ts
```

Works on macOS, breaks in Linux.

### 4) Top-level code throws during module evaluation

For example:

```ts
const x = window.location // throws in SSR-ish context
```

or accessing something undefined during import.
