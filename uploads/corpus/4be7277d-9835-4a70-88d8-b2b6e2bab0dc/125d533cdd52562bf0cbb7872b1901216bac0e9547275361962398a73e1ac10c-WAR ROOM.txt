0. Executive Summary (Plain English)

Nikodemus is an AI system designed to answer a single question:

“Can I believe this?”

Instead of trusting one AI, Nikodemus:
	•	runs multiple independent AI models
	•	forces them to reason over the same evidence
	•	surfaces disagreements explicitly
	•	produces a verifiable receipt showing what was said, by whom, with what support

Nikodemus does not decide truth.
It guarantees procedural integrity, transparency, and auditability.

Every mission maps to a locked configuration:

{
  "missionProfile": "EXEC_BRIEF",
  "verificationLevel": "STRICT",
  "evidencePolicy": {

9. Evidence Retrieval (Grounding Layer)
	•	Hub retrieves evidence once
	•	Same snapshot injected into all agents
	•	Evidence treated as data only
	•	Stored verbatim + hashed

⸻

10. Agent Output Contract (Mandatory)

{
  "text": "Claim statement",
  "stance": "AFFIRM | DENY | UNCLEAR",
  "confidence": 0.0,
  "evidence": [{ "ref": "ref_1", "quote": "..." }],
  "value": "optional normalized value"
}

Stance is non-negotiable.

⸻

11. Verification Engine (Deterministic)

11.1 Claim Clustering
	•	normalize text
	•	claimKey = sha256(normalized_text)

11.2 Dispute Types
	•	STANCE_CONFLICT (Yes vs No)
	•	VALUE_CONFLICT_NUMERIC
	•	VALUE_CONFLICT_CATEGORICAL
	•	MISSING_EVIDENCE (STRICT compliance failure)

11.3 Severity
	•	HIGH → categorical opposites
	•	MED → numeric/category mismatch

11.4 Corroboration (STRICT)

A claim enters synthesis only if:
	•	≥2 AFFIRM
	•	no disputes
	•	evidence present for all AFFIRM

⸻

12. Receipt (Trust Artifact)

Receipts are immutable summaries of a run.

Internal Receipt (Full)
	•	agent list
	•	evidence snapshot
	•	hashes
	•	timestamps

Public Receipt (Shareable)
	•	question
	•	date
	•	verification level
	•	consensus score
	•	dispute count
	•	evidence links
	•	no raw hashes or internals

⸻

13. Social Sharing (Safe by Design)
	•	share Public Receipt
	•	watermark verification level
	•	link back to full receipt (auth required)
	•	no raw agent outputs by default

This turns receipts into process proof, not screenshots.
